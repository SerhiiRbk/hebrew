# Схема данных сайта «Иврит A0→B2»

Все данные — обычные JS-файлы, подключаемые через `<script>` в `index.html`.
Каждый файл начинается со строки:

```js
window.HL = window.HL || {}; HL.data = HL.data || {};
```

и добавляет данные в соответствующий массив/объект. Это позволяет открывать сайт
и с GitHub Pages, и локально через `file://` (без fetch/CORS).

## Общие правила оформления

- **Иврит — всегда с полной огласовкой (никуд)**: `שָׁלוֹם`, а не `שלום`.
- **Транслитерация — кириллицей с ударением** комбинированным акутом (U+0301):
  `шало́м`, `бо́кер тов`. Звук «х» (ח, כ без дагеша) — `х`; «ц» — `ц`; «ш» — `ш`;
  гортанная ע/א не обозначается; шва подвижное — `э`: `бэ-ва-каша́`.
- **Перевод — на русском**, кратко, через `;` для нескольких значений.
- Уровни: `"A0" | "A1" | "A2" | "B1" | "B2"`.
- Род: `"m" | "f"`; число: `"pl"` только для слов, употребляемых во множественном.
- Часть речи `pos`: `n` (сущ.), `v` (глагол — в инфинитиве), `adj`, `adv`, `prep`,
  `pron`, `num`, `conj`, `phrase`, `q` (вопросительное слово), `part` (частица).

## 1. Словарь — `data/vocab/<level>.js`

```js
HL.data.vocab = HL.data.vocab || {};
HL.data.vocab.A0 = [
  { he: "שָׁלוֹם", tr: "шало́м", ru: "мир; привет; пока", pos: "n", g: "m",
    topic: "greetings",
    ex: "שָׁלוֹם, מָה שְׁלוֹמְךָ?", exTr: "шало́м, ма шломха́?", exRu: "Привет, как дела?",
    root: "ש.ל.מ", note: "Однокоренное с שָׁלֵם — целый, полный." },
  // ...
];
```

Поля `ex/exTr/exRu/root/note/pl` — необязательные. `pl` — форма множественного
числа с никудом (для существительных, у которых она нерегулярна или важна).

Ключи тем (`topic`) — только из списка в `data/topics.js`.

## 2. Грамматика — `data/grammar/<level>.js`

```js
HL.data.grammar = HL.data.grammar || [];
HL.data.grammar.push({
  id: "a1-present-paal",        // уникальный, латиницей
  level: "A1",
  order: 12,                    // порядок в общем курсе (сквозная нумерация)
  title: "Настоящее время: биньян פָּעַל",
  summary: "Одна строка — что изучаем и зачем.",
  body: `<p>HTML-текст урока...</p>
         <table class="tbl">...</table>`,
  exercises: [
    { type: "choice", q: "Выберите правильную форму: אֲנִי ___ (писать, ж.р.)",
      options: ["כּוֹתֵב", "כּוֹתֶבֶת", "כּוֹתְבִים"], answer: 1,
      explain: "Женский род ед.ч. в настоящем времени — суффикс ־ֶת." },
    { type: "fill", q: "הִיא ___ סֵפֶר (читать)", answer: ["קוֹרֵאת", "קוראת"],
      hint: "ж.р. ед.ч.", explain: "..." },
    { type: "order", q: "Соберите предложение: «Я живу в Тель-Авиве»",
      words: ["אֲנִי", "גָּר", "בְּתֵל אָבִיב"], answer: "אֲנִי גָּר בְּתֵל אָבִיב" }
  ]
});
```

Разрешённая разметка в `body`: `h3, h4, p, ul, ol, li, strong, em, table.tbl,
thead, tbody, tr, th, td, span.he (ивритский текст), span.tr (транслитерация),
div.tip (подсказка/лайфхак), div.warn (типичная ошибка), div.example (пример)`.
Внутри `.example` строки оформляются так:
`<span class="he">שָׁלוֹם</span> <span class="tr">шало́м</span> — привет`.

Каждый урок: 400–1200 слов объяснения, минимум одна таблица (если уместно),
раздел «Типичные ошибки русскоязычных», 4–8 упражнений.

## 3. Диалоги — `data/dialogues/<group>.js`

```js
HL.data.dialogues = HL.data.dialogues || [];
HL.data.dialogues.push({
  id: "supermarket", level: "A1", icon: "🛒",
  title: "В супермаркете", group: "Покупки",
  intro: "Ситуация: вы ищете молочный отдел и спрашиваете о цене.",
  lines: [
    { who: "A", name: "לָקוֹחַ", nameRu: "Покупатель",
      he: "סְלִיחָה, אֵיפֹה מוֹצְרֵי הַחָלָב?", tr: "слиха́, э́йфо мוцрэ́й hа-хала́в?",
      ru: "Извините, где молочные продукты?" },
    { who: "B", name: "עוֹבֵד", nameRu: "Работник", he: "...", tr: "...", ru: "..." }
  ],
  vocab: [ { he: "מִבְצָע", tr: "мивца́", ru: "акция, распродажа" } ],
  phrases: [ { he: "כַּמָּה זֶה עוֹלֶה?", tr: "ка́ма зэ оле́?", ru: "Сколько это стоит?" } ],
  culture: "Культурная заметка: ...",
  tasks: [ "Задание: разыграйте диалог, заменив ... на ..." ]
});
```

Диалог: 10–16 реплик, живой разговорный иврит (как реально говорят в Израиле),
`vocab` — 10–15 слов, `phrases` — 6–10 готовых фраз, `culture` — 2–4 предложения,
`tasks` — 2–3 задания. Знак ה в транслитерации — `h`: `hа-ба́йт`.

## 4. Тексты-образцы — `data/texts/<group>.js`

```js
HL.data.texts = HL.data.texts || [];
HL.data.texts.push({
  id: "about-me", level: "A1", icon: "👤", title: "Рассказ о себе (биография)",
  group: "О себе и семье",
  intro: "Как построить рассказ о себе: имя → возраст → откуда → где живу → работа → хобби.",
  plan: ["Имя и возраст", "Откуда приехал(а)", "..."],
  paragraphs: [
    { he: "שְׁמִי אַנָּה. אֲנִי בַּת שְׁלוֹשִׁים.", tr: "шми А́на. ани́ бат шлоши́м.",
      ru: "Меня зовут Анна. Мне тридцать лет." }
  ],
  template: [
    { he: "שְׁמִי ___.", ru: "Меня зовут ___." }
  ],
  vocab: [ { he: "נוֹלַדְתִּי", tr: "нола́дти", ru: "я родился / родилась" } ],
  questions: [ "מָה שִׁמְךָ?", "בֶּן כַּמָּה אַתָּה?" ],
  tips: ["Совет: ..."]
});
```

Текст: 8–14 предложений, каждая строка — отдельное предложение с переводом и
транслитерацией. `template` — каркас с пропусками для собственного рассказа.

## 6. Мнемоники — `data/mnemonics.js`

## 7. Темы — `data/topics.js`

Список тем словаря с русскими названиями и иконками; ключи используются в
поле `topic` словаря.
