# Иврит A0 → B2 — системный курс для русскоязычных

Бесплатный статический сайт для самостоятельного изучения иврита: алфавит, словарь с
интервальным повторением, подробная грамматика, диалоги из реальной жизни в Израиле,
тексты-образцы, мнемоники и девять интерактивных игр. Работает без сервера и сборки.

## Быстрый старт

Просто откройте `index.html` в браузере — или запустите любой статический сервер:

```bash
cd Hebrew && python3 -m http.server 8080
```

и откройте http://localhost:8080.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое каталога `Hebrew` в его корень
   (или положите каталог `Hebrew` в репозиторий целиком).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` — если файлы в корне, или `/docs`, если вы
   переименовали `Hebrew` в `docs`.
3. Через минуту сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

Файл `.nojekyll` уже есть — GitHub не будет обрабатывать сайт через Jekyll.
Все пути относительные, роутинг на `#hash`, поэтому сайт работает и в подпапке
репозитория, и локально через `file://`.

## Структура

```
Hebrew/
├── index.html            — оболочка, подключение данных и модулей
├── .nojekyll
├── css/style.css         — стили (светлая/тёмная тема, RTL, карточки, игры)
├── js/
│   ├── core.js           — утилиты, хранилище (localStorage), SRS, озвучка, роутер
│   ├── numbers.js        — генератор числительных 0–9999 (м./ж. род)
│   └── modules/
│       ├── pages.js      — главная, план курса, алфавит, мнемоники, прогресс
│       ├── vocab.js      — словарь и флеш-карточки (SM-2)
│       ├── grammar.js    — уроки, упражнения, таблицы спряжений, числительные
│       ├── dialogues.js  — диалоги и тексты-образцы (конструктор рассказа)
│       └── games.js      — 9 игр
└── data/
    ├── SCHEMA.md         — схема данных: как добавлять слова, уроки, диалоги
    ├── topics.js         — темы словаря и описания уровней
    ├── course.js         — методика и дорожная карта A0→B2
    ├── alphabet.js       — буквы и огласовки
    ├── vocab/{a0,a1,a2,b1,b2}.js
    ├── grammar/{a0,a1,a2,b1,b2}.js
    ├── dialogues/{everyday,institutions,tech-work}.js
    ├── texts/{personal,world}.js
    ├── verbs.js          — 50+ глаголов с полными парадигмами
    └── mnemonics.js      — ~100 мнемоник
```

## Как добавлять контент

Все данные — обычные JS-файлы. Формат каждого типа описан в
[`data/SCHEMA.md`](data/SCHEMA.md). Добавили файл — подключите его в `index.html`
рядом с остальными `<script src="data/…">`.

## Возможности

- **1174 слова** с огласовкой, транслитерацией, примером, родом и заметками, по 30 темам и 5 уровням (кухня, готовка, интерьер, тело, врачи-специалисты, погода, техника, финансы и др.).
- **Системный курс**: пять уровней, каждый с целями, грамматикой, темами лексики,
  диалогами, текстами и чек-листом «что я умею».
- **Карточки (SRS)**: алгоритм SM-2, режимы «иврит→русский», «русский→иврит»,
  «печатать на иврите», набор «Избранное».
- **Справочник**: большие статьи по системе языка — правила чтения (какая буква в каких парах как читается), род, число, «падежи» (чем иврит их заменяет и частица אֶת), предлоги, времена глаголов с наглядным разбором.
- **Устойчивые выражения**: 104 идиомы, коллокации и разговорные обороты по категориям, с дословным переводом, смыслом и примером.
- **Письма**: 8 образцов официальных и дружеских писем (хозяину квартиры, жалоба, работодателю, сопроводительное, в учреждение и др.) с планом, шаблоном и формулами обращения/прощания.
- **Английская транскрипция**: кнопка в шапке переключает транслитерацию всех слов и примеров между кириллицей и латиницей.
- **Грамматика**: 37 уроков с таблицами, разделом «Типичные ошибки русскоязычных»
  и упражнениями трёх типов (выбор, ввод, порядок слов).
- **Диалоги**: 36 ситуаций — магазин, рынок, кафе, поликлиника, банк, налоговая,
  Битуах Леуми, аренда, покупка компьютера, ремонт телефона, собеседование…
  Режимы: скрыть перевод/транслитерацию, ролевая игра, озвучка всего диалога.
- **Тексты-образцы**: биография, семья, квартира, работа, путешествия, еда…
  с планом, шаблоном-конструктором и вопросами для самопроверки.
- **Мнемоники**: звуковые, образные, сюжетные, родственные слова, корни.
- **Игры**: буквы, пары, «он или она?», собери фразу, спряжение, числа,
  собери слово, спринт, корни.
- **Озвучка** через Web Speech API (голос he-IL из системы), **переключатели**
  транслитерации и огласовок, тёмная тема, прогресс в localStorage с
  экспортом/импортом.
